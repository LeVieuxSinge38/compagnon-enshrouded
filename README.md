# Compagnon Enshrouded

Une petite appli Windows, gratuite, qui accompagne tes parties d'Enshrouded. Elle se glisse en overlay directement dans le jeu pour t'aider au quotidien : carte, builds, ressources, et tout le reste.

## Télécharger

Rends-toi ici : [CompagnonEnshrouded.zip](https://github.com/LeVieuxSinge38/compagnon-enshrouded/releases/latest/download/CompagnonEnshrouded.zip)

Puis :

1. Dézippe l'archive où tu veux (Dossier `CompagnonEnshrouded` par exemple).
2. Lance `CompagnonEnshrouded.exe`.
3. Au tout premier lancement, l'appli télécharge ses pages web (quelques secondes, c'est normal).
4. C'est parti !

> **Windows SmartScreen** peut t'afficher un avertissement parce que l'appli n'est pas signée. C'est normal, ce n'est pas un virus. Clique sur **« Informations complémentaires »** puis **« Exécuter quand même »**.

## Prérequis

- Windows 10 ou 11
- [WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) (déjà installé sur Windows 11, à installer manuellement sur Windows 10 si ce n'est pas fait)

## Fonctionnalités

- **Assistant de premier lancement** : tu lui donnes ton pseudo, c'est tout.
- **Détection de tous tes personnages** via les sauvegardes du jeu, avec bascule automatique quand tu changes de perso.
- **Carte interactive** pour te repérer dans le monde.
- **Builds** et **arbre de compétences** pour progresser sans te perdre.
- **Ressources et fabrication** : savoir où trouver quoi, et comment le fabriquer.
- **Provenance de l'équipement** : d'où vient chaque objet, comment l'obtenir.
- **Overlay en jeu** : tout ça directement par-dessus Enshrouded, sans alt-tab.
- **Mises à jour automatiques** : l'appli se met à jour toute seule, sans que tu aies à la fermer.

## Vie privée

Pas de compte, pas de tracking, pas de serveur. Tout reste sur ton PC.

- Les sauvegardes du jeu sont **seulement lues**, jamais modifiées.
- Les seules connexions sortantes sont :
  - **GitHub** → pour les mises à jour de l'appli.
  - **Steam** → pour récupérer les actualités du jeu.
  - **Google Traduction** → pour traduire ces actualités en français.

C'est tout. Rien d'autre ne sort de ta machine.
